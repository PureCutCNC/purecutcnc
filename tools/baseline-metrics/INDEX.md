# INDEX — tools/baseline-metrics/

Read-only WP0 baseline harness for the SolidCraft pattern adoption.

- `metrics.ts` — pure metric helpers: fixture summary, embedded-asset byte
  count, Node parse/stringify/clone timing, serialized 100-entry history
  projection, command-source pattern counts.
- `metrics.test.ts` — structural coverage for the helpers.
- `run.ts` — CLI over the checked-in `.camj` fixtures, `src/commands/` and
  `canvasShortcuts.ts`. Writes optional JSON/Markdown; default output is a
  concise console summary.
- `baseline.json` / `BASELINE.md` — generated by the command below; not a gate.

```bash
npx tsx tools/baseline-metrics/run.ts \
  --json tools/baseline-metrics/baseline.json \
  --markdown tools/baseline-metrics/BASELINE.md
```

Timing is Node serialization cost, not a full app load. The history number is a
serialized-size projection (`snapshotBytes × 100`), not V8 heap usage.
