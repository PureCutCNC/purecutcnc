## The idea (approved plan)

Unroll the bar's surface flat. Everything PureCutCNC does on a flat block then
works on that surface: an Around operation is generated by handing the
unchanged generators a flat block (bar length x circumference, one radius
thick) and wrapping the resulting toolpath back onto the bar, where the
distance around becomes the rotary angle `a` on each toolpath point (#393).
No generator learns that a bar exists.

This slice builds that as pure engine code with tests. Nothing in the UI, the
store, file loading or export can create or show an Around setup yet; later
slices do that. So do not add Around behaviour anywhere outside the files
named below.

### New module `src/engine/aroundFrame.ts`

Conventions (state them in the module header):

- The bar is a `RoundStock`: `thickness` is its diameter `D`, radius
  `R = D / 2`, `axis` is the project axis it lies along. "Along" is the
  coordinate on that axis; "across" is the other horizontal coordinate
  (`y` for a bar along X, `x` for a bar along Y). X and Y are never swapped.
- The unrolled sheet keeps the bar's extent along, and across it runs from
  `sheetStart` (the bar's own minimum across coordinate, from
  `getStockBounds`) to `sheetStart + C`, `C = π · D`. Geometry may lie outside
  that range: more distance is simply more rotation.
- A feature on Around stores its heights exactly like a Top feature on the
  same bar: the surface is `z = D`, depth goes down towards the centreline at
  `z = R`. In the flat frame heights are lowered by `R`: the flat block is `R`
  thick, its top (`z = R`) is the bar's surface and its bottom (`z = 0`) is
  the centreline.
- Angle from distance: `a = 360 · (across − sheetStart) / C` degrees. It is
  never reduced to 0–360.
- Sign: this is the convention frozen in `rotaryFrame.ts`. With `r` the flat
  height (distance from the centreline) and `a` as above, the stock point
  being cut is `across = centre + r·sin a`, `z = R + r·cos a`, and
  `toolSpacePoint` of that stock point at `a` is the wrapped point.

```ts
export interface AroundFrame {
  readonly axis: 'x' | 'y'
  /** The centreline's across coordinate (roundStockCentre). */
  readonly centre: number
  readonly radius: number
  /** Across coordinate of the sheet's zero line: the top of the bar at a = 0. */
  readonly sheetStart: number
  readonly circumference: number
}
export function aroundFrame(stock: RoundStock): AroundFrame
/** The frame for an operation in an Around setup, else undefined. Throws when
 *  the setup is Around but the stock is not a round bar, or the setup's axis
 *  is not the bar's axis: fail closed, never guess. */
export function aroundFrameForOperation(
  project: Pick<Project, 'setups' | 'stock'>,
  operation: Pick<Operation, 'id' | 'setupId'>,
): AroundFrame | undefined
/** Flat point -> tool point on the bar. Always carries `a`. */
export function wrapPoint(flat: { x: number; y: number; z: number }, frame: AroundFrame): ToolpathPoint
/** Exact inverse of wrapPoint. Throws on a point with no `a`. Result has no `a` key. */
export function unwrapPoint(point: ToolpathPoint, frame: AroundFrame): { x: number; y: number; z: number }
/** The project as a flat block for the generators. Transient; never stored. */
export function unrolledProject(project: Project, frame: AroundFrame): Project
/** A toolpath generated on the flat block, carried onto the bar (stock space). */
export function wrapToolpath<T extends ToolpathResult>(result: T, frame: AroundFrame): T
/** A wrapped toolpath back on the flat block (for simulation and reports later). */
export function unwrapToolpath<T extends ToolpathResult>(result: T, frame: AroundFrame): T
```

`wrapPoint`, closed form (do not route it through sin/cos): for a bar along X
`{ x: flat.x, y: centre, z: flat.z + radius, a }`; for a bar along Y
`{ x: centre, y: flat.y, z: flat.z + radius, a }`. The tool therefore always
sits exactly over the centreline.

`unrolledProject`:

- `stock`: a plain block (`rectProfile`; no `shape`, no `axis`, no
  `sourceFeature`), bar length along, `[sheetStart, sheetStart + C]` across,
  `thickness: radius`.
- `features`: only those with `authoringFace === 'around'`, `z_top` and
  `z_bottom` resolved to numbers (`resolveDimensionRef`, as `turnFeature`
  does) and lowered by `radius`. Features of other faces are left out.
- `tabs`: none. `clamps`: only `type` `'chuck'` and `'tailstock'`, each as a
  band: its extent along kept, its extent across replaced by the whole sheet
  `[sheetStart, sheetStart + C]`. Look at how `Clamp.height` is read
  (`src/engine/toolpaths/clamps.ts`) and keep the clamp's top the same
  distance above the stock's top surface as it is on the real bar; say in the
  report what `height` is measured from.
- `origin`: `z` lowered by `radius`; nothing else.
- `setups`: every Around setup loses its `kind`, so the result reads as an
  ordinary top-down project and nothing unrolls it twice.
- Everything else passes through. The input project is not mutated.

`wrapToolpath`:

- Every move's `from` and `to` wrapped, order kept, `kind`, `source` and
  `feedScale` kept.
- **Split rule.** Export computes a turning move's inverse-time feed from the
  mean of its two radii (`inverseTimeFeedValue` in
  `src/engine/gcode/motionPipeline.ts`, read only). So a move whose angle
  changes **and** whose height changes is split into `n` equal pieces in the
  flat frame before wrapping, `n = min(64, ceil(|Δz| / (0.1 · max(min(z_from, z_to), ε))))`
  with flat heights and a small positive `ε`, so no piece changes radius by
  more than about a tenth. Moves that only turn, or only change height, are
  not split. `collidingMoveIndices` must be remapped to the pieces.
- `bounds` re-measured from the wrapped points.
- `drillCycles` removed: on Around a hole is always written as plain moves,
  never a canned cycle (approved policy). Confirm in the code that a drilling
  result's `moves` already contain the full expanded motion whenever
  `drillCycles` is present, and say so in the report; if they do not, STOP and
  report.
- `stepLevels` (pocket results) raised by `radius`.

`unwrapToolpath`: the inverse on points (pieces stay split), `bounds`
re-measured, `stepLevels` lowered, no `a` on any point.

const around = aroundFrameForOperation(project, operation)
if (around) {
