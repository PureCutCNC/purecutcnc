## F8 — true cutter width in the wrapped simulation kernel (round and square alike)
The kernel (src/engine/simulation/replay.ts applyMoveToGrid / tools.ts cutterSurfaceZ) works in the unrolled sheet: a cell at across distance u from the tool line (arc length at the frame radius R0) is treated like flat milling: lowered to the cutter's surface at horizontal distance sqrt(dx^2 + u^2). Physically the cutter points along the pass ray; a cell is a ray at angle D = u / R0 from it, and a point of that ray at radius r sits r*sin(D) across and r*cos(D) along the cutter axis. Measured: on a 25 mm square (corner radius 17.7 vs R0 12.5) the kernel lowers retained-end corner cells by up to 0.92 mm (flat) / 0.73 mm (ball) at spots the real cutter never reaches (checked exactly); on round bars it under-removes on groove walls cut below R0.
Change, for wrapped (Around) grids only: per cell, compute the exact removed interval of the ray [r_lo, r_hi] for the cutter at that position: flat cylinder (|across| <= w(dx) = sqrt(rt^2 - dx^2) with the flat bottom at the tip), ball (sphere centre at tip + rt on the axis, plus the shank cylinder above the centre), V-bit (its cone and shank) using the same tool dimensions the kernel already has. The heightfield keeps one radius per cell, so: if the cell's current top <= r_hi, lower it to r_lo when r_lo < top; if top > r_hi (the cutter passes through the middle of the ray and the outer part survives), leave the cell unchanged. Never raise a cell. Keep seam copies, dirty regions, stats and playback semantics. Flat (non-wrapped) grids byte-identical. Keep it fast: closed form per cell, no sampling; report the timing on the 25 mm case at detail 280 (was ~10 ms).
Tests (new src/engine/simulation/wrappedCutterGeometry.test.ts): per-cell result vs an independent dense physical oracle (sample points along each ray, test inside the exact cutter solid) on random moves for flat/ball/V, round and square starts, both A senses, seam; the 25 mm square-to-round case: zero cells lowered in the retained ends; a round-bar groove: walls now match the oracle; flat-grid replay byte-identical (existing tests unchanged); playback batch == subdivided; reset restores.
